
# 🔐 Python User Management System

A command-line user management application developed in Python as part of my software development coursework.

This project explores user account management, role-based functionality, and foundational application security concepts.

## 📖 About the Project

The Python User Management System was developed to practice programming fundamentals, file handling, user input processing, and access control.

The project was also used to identify and improve security-related logic, particularly around user roles and administrative privileges.

## ✨ Features

- Command-line user interface
- User account management
- User role handling
- File-based user data storage
- Input processing and validation logic
- Administrative functionality
- Security-focused code improvements

## 🛠️ Technologies Used

- Python
- File I/O
- Conditional logic
- Functions
- Git and GitHub
- Visual Studio

## 🔐 Security Learning

### Role-Based Access Control

The project explores the difference between regular users and administrators.

A key improvement involved preventing users from assigning themselves administrative privileges during account creation.

### Security Limitations

This is an educational project and is not intended for production use.

Areas requiring further improvement include:

- Secure password hashing and storage
- Authentication hardening
- Consistent server-side authorization checks
- Improved input validation
- Automated security testing
